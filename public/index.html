How it works

One passive look at the homepage. Nothing is crawled, probed or exploited; the tool reports what it saw and says so when it saw nothing.

1. One request
A HEAD request to the homepage, then a GET when HEAD is refused or shows nothing. Up to five redirects are followed, with an identifying User-Agent.
2. Read the headers
PHP announces itself as X-Powered-By: PHP/8.4.26, sometimes inside Server. PHPSESSID cookies, WordPress, Drupal and Laravel markers and links to .php files separate "PHP, version hidden" from "no PHP at all".
3. Compare with php.net
Release data is fetched live from php.net and endoflife.date: latest patch per branch, active or security-only support, end-of-life dates, and the known critical advisories.
4. Hand it to an agent
Each result comes with a prompt that lists the evidence, the current releases and the check, confirm, fix and verify steps. Open it in Claude, ChatGPT, Grok, Gemini or Perplexity.

Most sites hide the version on purpose. PHP only sends X-Powered-By when expose_php = On. Well-configured hosts, Docker images, managed platforms and CDNs turn it off or strip it, so most results read "PHP, version hidden" or "no signal". That is not a failed check: the patch level can then only be confirmed from inside the server, which is what the agent prompt walks through. When a version is exposed it is reliable, and a small finding in itself.

Prompts for agents

Every result has its own prompt with the observations filled in. These are the generic templates behind it. Replace {{domain}}, or open one directly in your assistant.

What the verdicts mean

latest
Exposed version equals the newest patch on its branch.
outdated
Same branch, older patch. When the newest patch is a security release, treat as urgent.
EOL
Branch no longer receives fixes at all.
distro build
Debian, Ubuntu or RHEL package. The number lags upstream on purpose; backported fixes may be present. Needs an inside check.
partial
Only "PHP/8.x" exposed, no patch level.
PHP, version hidden
PHP markers present but no version. Good hygiene; only an inside check gives the patch level.
no signal
Nothing PHP-related observed. Hidden, not PHP, or stripped by a CDN.
unreachable
No HTTP response over https or http.
