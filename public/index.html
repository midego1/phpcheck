How it works

  1. One HEAD request to the homepage, GET when needed, up to five redirects.
  2. Version read from X-Powered-By or Server. PHPSESSID, CMS markers and .php links separate "PHP, version hidden" from "no PHP".
  3. The same response is graded for security headers and cookie flags, scanned for JavaScript libraries against the Retire.js database, and for WordPress core, plugin and theme vulnerabilities against the Wordfence Intelligence feed, plus web server versions.
  4. Compared with php.net, endoflife.date, wordpress.org and Retire.js, cached six to twenty-four hours.
  5. Each result gets a check, confirm, fix and verify prompt for your agent.

Most sites hide the version on purpose. PHP only sends X-Powered-By when expose_php = On; good hosts, Docker images and CDNs turn it off or strip it. "Version hidden" is expected, not a failed check. The patch level is then confirmed from inside, which is what the prompt walks through.
