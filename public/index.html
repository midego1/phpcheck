How it works

  1. One HEAD request to the homepage, GET when needed, up to five redirects.
  2. Version read from X-Powered-By or Server; PHPSESSID, CMS markers and .php links tell "PHP, version hidden" from "no PHP".
  3. Compared with php.net and endoflife.date, cached six hours.
  4. Each result gets a check, confirm, fix and verify prompt for your agent.

Most sites hide the version on purpose. PHP only sends X-Powered-By when expose_php = On; good hosts, Docker images and CDNs turn it off or strip it. "Version hidden" is expected, not a failed check: the patch level is then confirmed from inside, which is what the prompt walks through.

Verdicts

latest
Newest patch on its branch.
outdated
Same branch, older patch.
EOL
Branch gets no fixes any more.
distro build
Debian/Ubuntu/RHEL package; fixes may be backported. Check inside.
partial
Only "PHP/8.x" exposed.
PHP, hidden
PHP markers, no version. Check inside.
no signal
Nothing PHP-related seen.
unreachable
No HTTP response.
