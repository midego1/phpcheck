How to check which PHP version a website uses

A site only tells you its PHP version if the server exposes it. Here is what to look at, what it can and cannot prove, and how PHP Check automates it.

1. Read the response headers

Many servers send the PHP version in an X-Powered-By header. Request just the headers:

curl -sI https://example.com | grep -i x-powered-by
X-Powered-By: PHP/8.2.12

The Server header can also name PHP when it runs as an Apache module, for example Apache/2.4.58 (Ubuntu) PHP/8.2.12.

2. When the version is hidden

Setting expose_php = Off in php.ini removes the X-Powered-By header, and many hosts and CDNs strip it anyway. No header means the version is not exposed, not that the site is not running PHP. Other hints, such as .php URLs, PHPSESSID cookies or WordPress markup, show PHP is in use but not which version. Those hints are not a version number, so PHP Check reports the version as unknown rather than guessing.

3. Compare with supported releases

A version number only matters next to the current releases. Each PHP branch moves through active support, security-only support and end of life. Running 8.2.12 when 8.2.x has a newer patch release means missing fixes; running a branch past end of life means no more security fixes at all. The official list is on php.net.

Doing it with PHP Check

Enter one or more domains on the PHP Check homepage. It requests only each site's homepage, reads the exposed PHP version, compares it with the current releases from php.net, and writes a check-and-fix prompt for your agent. It handles up to 300 domains at once. The same check is available over the JSON API and the MCP endpoint, both described on the homepage. The code is open source.
